INSTRUCTOR RESOURCE KIT — ACCESS AND UNLOCK INSTRUCTIONS

This package contains InstructorKit.7z, a compressed archive
protected with AES-256 encryption and a password. Filenames are also encrypted.

HOW TO REQUEST THE UNLOCK KEY
Email Saaid J Elhadad at saaid.elhadad@ctstate.edu.
Suggested subject: Instructor Resource Kit — Unlock Key Request
Include your name, institution, course or teaching role, and the reason you
need access. Request the password for InstructorKit.7z.
The kit owner will review your request and provide the key if approved.

HOW TO UNLOCK THE KIT
1. Save InstructorKit.7z to your computer.
2. Open it with an archive application that supports encrypted 7z files
   (for example, 7-Zip).
3. Choose Extract and enter the password exactly as supplied by the owner.
4. Choose a destination folder and complete extraction.

The encrypted archive contains the original kit files and folder structure.
Some documents may have their own existing protection; request any additional
credentials from the kit owner if needed.

Keep the password private and share it only with the owner's authorization.
The unlock key is provided separately and is not included in this package.
